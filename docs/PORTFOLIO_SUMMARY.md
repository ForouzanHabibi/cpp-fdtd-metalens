# Portfolio / CV Summary

## GitHub short description
C++ 2D TMz FDTD metalens simulator with CPML, verified discrete phase library, Poynting-flux normalization, subpixel geometry averaging, full-device convergence checks, and broadband Fourier analysis.

## CV bullets
- Developed a custom **C++ 2D TMz FDTD solver** with Yee updates, CPML, periodic/open boundaries, complex Fourier monitors, Poynting-flux power normalization, OpenMP parallelization, and subpixel dielectric averaging.
- Built and verified an **8-state discrete phase library at 1550 nm**, then assembled a 21-cell finite metalens and performed full-device grid stabilization.
- Obtained a preferred **64.8% incident-power-normalized 2D focusing efficiency** in a 3×FWHM focal window with **1.38 µm lateral FWHM** using the 25-nm subpixel model.
- Performed broadband analysis of the idealized nondispersive model and localized a continuous **80%-retention interval of approximately 1.43–2.39 µm**, with a narrow long-wavelength recovery region treated separately.
